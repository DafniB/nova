# NOVA Fashion Store 👗 An interactive **modern fashion e-commerce website** built using **HTML, CSS, and JavaScript**. This project demonstrates a stylish clothing store UI with a shopping cart system, responsive layout, and dynamic product rendering. --- ## 🌐 Live Features * Modern fashion landing page * Interactive product cards * Add to cart functionality * Sliding cart panel * Dynamic product rendering with JavaScript * Responsive layout for mobile and desktop * Smooth scrolling shopping experience --- ## 🖼 Preview Hero fashion landing page with featured clothing items and a modern store interface. --- ## 🛠 Technologies Used * **HTML5** * **CSS3** * **JavaScript (Vanilla JS)** * **Google Fonts** * **Unsplash Images** --- ## 📂 Project Structure ``` nova-fashion-store │ ├── index.html # Main website file └── README.md # Project documentation ``` --- ## 🚀 How to Run the Project 1. Clone the repository ``` git clone https://github.com/yourusername/nova-fashion-store.git ``` 2. Open the project folder 3. Run the website by opening: ``` index.html ``` in your browser. --- ## ✨ Features ✔ Interactive shopping UI ✔ Animated cart drawer ✔ Dynamic product rendering ✔ Clean fashion-style layout ✔ Mobile responsive design --- ## 📸 Product Data Products are dynamically generated using a JavaScript array: ``` const products = [ { name: "Summer Floral Dress", price: 49 }, { name: "Black Evening Dress", price: 89 }, ... ] ``` This allows easy expansion to connect with a backend or API later. --- ## 🔮 Future Improvements * Product detail page * Wishlist system * Search and category filtering * Checkout page * Payment gateway integration * Backend database * User authentication --- ## Screenshots ## 👨‍💻 Author Created by **Dafni** --- ## 📄 License This project is open-source and free to use.
