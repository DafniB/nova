# NOVA Fashion Store 👗

An interactive **modern fashion e-commerce website** built using **HTML, CSS, and JavaScript**.

This project demonstrates a stylish clothing store UI with a shopping cart system, responsive layout, and dynamic product rendering.

---

## 🌐 Live Features

* Modern fashion landing page
* Interactive product cards
* Add to cart functionality
* Sliding cart panel
* Dynamic product rendering with JavaScript
* Responsive layout for mobile and desktop
* Smooth scrolling shopping experience

---

## 🖼 Preview

Hero fashion landing page with featured clothing items and a modern store interface.

---

## 🛠 Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript (Vanilla JS)**
* **Google Fonts**
* **Unsplash Images**

1. Clone the repository

3. Run the website by opening:

```
index.html
```

in your browser.

## 📸 Product Data

Products are dynamically generated using a JavaScript array:

```
const products = [
  { name: "Summer Floral Dress", price: 49 },
  { name: "Black Evening Dress", price: 89 },
  ...
]
```

This allows easy expansion to connect with a backend or API later.
